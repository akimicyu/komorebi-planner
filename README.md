# こもれび計画

個人や小さなチームで、イベント準備などの計画を管理するガントチャートツールです。

**公開サイト：** https://akimicyu.github.io/komorebi-planner/

月額料金・アカウント登録・アプリ専用サーバーは不要です。ブラウザで編集し、プロジェクトをJSONファイルに保存します。HTMLをダウンロードしてローカルで使うこともできます。

## 機能

- タスク、担当者、開始・終了日、進捗率、実績日、メモの編集
- 担当者候補の記憶とJSONへの保存
- 終了→開始の依存関係と待ち日数、循環の検出
- 選択した目標までの余裕日数とクリティカルパス
- 基準計画・現在計画・実績期間の比較
- 進捗率による簡易イナズマ線
- 画面幅に合わせた表示、月・週・日表示、チャート拡大表示
- JSONの読込・保存、ブラウザ内の自動保存、印刷/PDF

## 使い方

公開サイトを開くか、リポジトリの `index.html` を保存してブラウザで開きます。最初は架空の講演会準備サンプルを表示します。行やバーをクリックして編集し、「JSON保存」でプロジェクトを書き出します。

ローカル版と公開版ではブラウザ内の保存領域が異なります。移行するときは、元の画面でJSON保存し、移行先の「JSONを開く」で読み込んでください。ローカル版HTMLをこのリポジトリ版に置き換える場合も、先にJSONで保存してください。

[操作方法・計算ルール](USAGE.md)を参照してください。

## 保存と共有

JSONがプロジェクトの正本です。共有ストレージへ置き、編集は1人ずつ行ってください。同時編集・自動マージはありません。自動保存はブラウザ内の1プロジェクト分で、JSONファイルには自動反映しません。

計画データを送信する処理やアクセス解析はありません。公開サイトのHTML配信はGitHub Pagesが行います。ローカルのHTMLは外部リソースを読み込まずに動作します。

## 計算の範囲

期間は暦日で、休日カレンダー・個人の稼働率・工数・費用は計算しません。開始日は「これより前には開始しない日」として扱います。クリティカルパスは現在の計画と依存関係から計算し、進捗や実績から残期間を自動予測しません。イナズマ線は期間×進捗率による簡易方式です。詳細は使い方をご確認ください。

## 開発

Node.js 18以降。開発時は最初に `npm ci` を実行してください。依存パッケージは整形用のPrettierのみで、配布するHTMLの実行時には不要です。

```sh
npm run check
```

書式確認、構文確認、ロジックのテスト、HTMLの生成を実行します。

```sh
npm run format        # ソース・テンプレート・テストを整形
npm run format:check  # 書式の確認だけを実行
```

```text
src/app.js          編集・保存・計算・チャート描画
src/template.html   画面構造とスタイル
scripts/build.mjs   ソースをHTML1枚にまとめる
index.html          生成済みアプリ・GitHub Pagesの公開入口
tests/core.cjs     ロジックの検証
USAGE.md            利用者向けの説明
```

`src/app.js` は次の順に整理しています。

- 日付変換・HTMLエスケープなどの共通処理
- 依存矢印の経路計算、日程と総余裕の計算
- JSONの検証と担当者履歴、講演会サンプルの生成
- `initializeApp()` 内のブラウザ状態、自動保存
- `render()` から呼ぶ日付軸・バー・矢印・イナズマ線の描画関数
- タスク編集・JSON保存読込の操作関数と、`bindEvents()` のイベント登録

ブラウザ内の自動保存とJSONファイルへの保存は別の処理です。保存形式・localStorageのキーは互換性を維持しています。

`src/` を編集したら `npm run check` を実行し、生成された `index.html` も一緒にコミットします。

## 公開

GitHub Pagesの公開元は `main` ブランチのルート `/` です。ビルド済みのHTMLをコミットするため、独自のGitHub Actionsやサーバー設定は不要です。`main` にpushするとGitHub Pagesへ反映されます。

実際のプロジェクトJSON・バックアップ・スクリーンショットはリポジトリへ追加しないでください。必要ならGit管理対象外の `private/` や `backups/` に保存できます。
