# こもれび計画

個人や小さなチームで、イベント準備などの計画を管理するガントチャートツールです。

**公開サイト：** https://akimicyu.github.io/komorebi-planner/

月額料金・アカウント登録・アプリ専用サーバーは不要です。ブラウザで編集し、プロジェクトをJSONファイルに保存します。HTMLをダウンロードしてローカルで使うこともできます。

## 機能

- タスク、担当者、開始・終了日、進捗率、実績日、メモの編集
- 担当者候補の記憶とJSONへの保存
- 終了→開始の依存関係と待ち日数、循環の検出
- 選択した目標までの余裕日数とクリティカルパス
- 基準計画・現在計画・実績期間の比較
- 進捗率による簡易イナズマ線
- 画面幅に合わせた表示、月・週・日表示、チャート拡大表示
- JSONの読込・保存、ブラウザ内の自動保存、印刷/PDF

## 開発

Node.js 18以降が必須(22などEOL前のLTSを推奨)。開発時は最初に `npm ci` を実行してください。依存パッケージは整形用のPrettierのみで、配布するHTMLの実行時には不要です。

```sh
npm run check
```

書式確認、構文確認、ロジックのテスト、HTMLの生成を実行します。

```sh
npm run format        # ソース・テンプレート・テスト・利用説明を整形
npm run format:check  # 書式の確認だけを実行
```

```text
src/app.js          編集・保存・計算・チャート描画
src/template.html   画面構造とスタイル
src/icon.svg        ヘッダーアイコンとファビコンの共通デザイン
scripts/build.mjs   ソースと利用説明をHTML1枚にまとめる
scripts/help.mjs    利用説明のMarkdownをHTMLへ変換
index.html          生成済みアプリ・GitHub Pagesの公開入口
tests/core.cjs      計算ロジックの検証
tests/ui.cjs        画面操作ロジックの検証（ブラウザは使わない）
tests/help.mjs      利用説明のHTML変換の検証
USAGE.md            利用者向け説明の正本
```

`src/app.js` は次の順に整理しています。

- 日付変換・HTMLエスケープなどの共通処理
- 依存矢印の経路計算、日程と総余裕の計算
- JSONの検証と担当者履歴、講演会サンプルの生成
- `initializeApp()` 内のブラウザ状態、自動保存
- `render()` から呼ぶ日付軸・バー・矢印・イナズマ線の描画関数
- タスク編集・JSON保存読込の操作関数と、`bindEvents()` のイベント登録

ブラウザ内の自動保存とJSONファイルへの保存は別の処理です。保存形式・localStorageのキーは互換性を維持しています。

利用者向けの操作・保存方法・計算ルールは `USAGE.md` だけを編集します。`npm run build` がMarkdownをHTMLに変換し、`src/template.html` の `<!--USAGE-->` へ埋め込みます。アプリ内ヘルプの本文をテンプレートに直接書かないでください。見出し（`#`・`##`・`###`）、段落、番号付きリスト、箇条書き、インラインコードに対応しています。依存パッケージや実行時の通信は追加しません。

`src/`・`USAGE.md`・ビルド処理を編集したら `npm run check` を実行し、生成された `index.html` も一緒にコミットします。

## 公開

通常の開発は `develop` ブランチで行います。変更後は `npm run check` を実行し、生成された `index.html` も一緒にコミットしてください。`develop` へのpushでは公開サイトは更新されません。

公開するタイミングで `develop` の変更を `main` にマージし、`main` をpushします。GitHub Pagesの公開元は `main` ブランチのルート `/` です。ビルド済みのHTMLをコミットするため、独自のGitHub Actionsやサーバー設定は不要です。

実際のプロジェクトJSON・バックアップ・スクリーンショットはリポジトリへ追加しないでください。必要ならGit管理対象外の `private/` や `backups/` に保存できます。
